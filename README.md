Entrants write one status update of 120 characters at most in the voice of a lost sock. An AI judge reads them two at a time and the funniest line takes the whole reward.

## The entry

> Lost sock update: I've started a new life inside the sofa cushions. Rent is crumbs. The remote is my roommate.

## Run it

```sh
python3 main.py
```

It writes the status update verbatim to `/output/entry.txt` and prints it.
